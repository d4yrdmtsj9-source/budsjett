# Renover

Privat renovasjonsbudsjett for to personer (NOK).

## Kjør lokalt (gratis)

```bash
npm install
npm run dev
```

Åpne http://localhost:5173

## Hosting uten Lovable-credits

Appen er ferdig i dette repoet og snakker med den eksisterende Supabase-databasen.

### GitHub Pages (gratis)

1. [Aktiver Pages](https://github.com/d4yrdmtsj9-source/budsjett/settings/pages)
2. Source: **Deploy from a branch** → `gh-pages` / `/ (root)` → Save
3. Åpne: https://d4yrdmtsj9-source.github.io/budsjett/

## Funksjoner

- Innlogging + opprett/bli med via invitasjonskode (maks 2)
- Dashboard, rom, utgifter, leverandører, innstillinger
- Hurtig «Legg til utgift» med live total, status, rabatt, kvittering
- Sanntidsoppdateringer mellom begge brukerne

## Lovable

Lovable-prosjektet krever credits for videre agent-endringer. Denne appen trenger **ikke** Lovable for å fungere.
