# Renover

Renovasjonsbudsjett for to personer (NOK). **Ingen konto eller e-post.**

## Bruk appen her

**https://d4yrdmtsj9-source.github.io/budsjett/**

### Start
1. Skriv navnet ditt → **Start prosjekt**
2. Del invitasjonskoden under **Innstillinger**

### Partner / ny enhet
1. **Åpne / bli med** → skriv invitasjonskoden
2. Velg **Fortsett som [ditt navn]** — ikke lag en ny person

Endringer lagres i skyen. Den andre enheten trenger ikke å være åpen. Ta gjerne en sikkerhetskopi (Eksporter) under Innstillinger.

### Legg til person
**Innstillinger → Personer → Legg til**

## Lokalt

```bash
npm install
npm run dev
```
